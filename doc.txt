1Generate API Key

Klik Generate Key di atas, beri label deskriptif (misal: Production atau Staging), lalu simpan key yang muncul — hanya ditampilkan sekali dan tidak bisa dilihat lagi.
2Kirim request dengan header X-API-Key

Sertakan API key di setiap request menggunakan header X-API-Key. Semua endpoint memerlukan autentikasi ini.
X-API-Key: sk_live_xxxx...
Content-Type: application/json
3Contoh Code

Pilih fitur dan bahasa pemrograman:

1. INVOICE
const API_KEY = 'sk_live_xxxx...'
const BASE    = 'https://api.sayabayar.com/v1'
const headers = { 'Content-Type': 'application/json', 'X-API-Key': API_KEY }

// Buat invoice baru
const res = await fetch(`${BASE}/invoices`, {
  method: 'POST', headers,
  body: JSON.stringify({
    customer_name: 'Budi Santoso',
    customer_email: 'budi@example.com',
    amount: 150000,
    description: 'Pembelian produk X',
    channel_preference: 'client',
    payment_method: 'qris',
    redirect_url: 'https://toko-anda.com/order/success'
  })
})
const invoice = await res.json()
console.log('Payment URL:', invoice.data.payment_url)

// Cek status
const detail = await fetch(`${BASE}/invoices/${invoice.data.id}`, { headers })
console.log('Status:', (await detail.json()).data.status)

// Konfirmasi pembayaran (QRIS & bank transfer)
await fetch(`${BASE}/invoices/${invoice.data.id}/confirm`, { method: 'POST', headers })

2. COnnect CHannel
// Tahap 1: Verify → list outlets
const verify = await fetch(`${BASE}/channels/connect/verify`, {
  method: 'POST', headers,
  body: JSON.stringify({
    channel_type: 'qris_mandiri',
    username: '081234567890',
    password: 'password_livin_merchant'
  })
})
const { data: { outlets } } = await verify.json()

// Tahap 2: Connect outlet → create channel
const connect = await fetch(`${BASE}/channels/connect`, {
  method: 'POST', headers,
  body: JSON.stringify({
    channel_type: 'qris_mandiri',
    username: '081234567890',
    password: 'password_livin_merchant',
    outlet_id: outlets[0].id,
    // qris_string: '00020101021226...',  // opsional: fallback bila bank tidak kirim QRIS (mis. Mandiri PNG gagal decode)
  })
})
console.log('Channel ID:', (await connect.json()).data.id)

Parameter payment_method

Gunakan payment_method pada POST /v1/invoices untuk langsung menentukan metode pembayaran. Jika tidak diisi, customer akan memilih sendiri di halaman pembayaran.
Nilai	Metode	Prasyarat
qris	QRIS	—
bca_transfer	Transfer Bank BCA	—
va_bca	VA Bank BCA	KYC + VA aktif
va_bni	VA Bank BNI	KYC + VA aktif
va_bri	VA Bank BRI	KYC + VA aktif
va_mandiri	VA Bank Mandiri	KYC + VA aktif
va_permata	VA Bank Permata	KYC + VA aktif
va_cimb	VA CIMB Niaga	KYC + VA aktif
va_bsm	VA BSI (Bank Syariah Indonesia)	KYC + VA aktif
va_danamon	VA Bank Danamon	KYC + VA aktif
va_seabank	VA SeaBank	KYC + VA aktif
⚡ Virtual Account: Untuk menggunakan VA, pastikan KYC sudah diverifikasi dan fitur VA sudah diaktifkan di menu Virtual Account. Biaya admin mulai dari Rp 3.000/transaksi. Pembayaran terdeteksi otomatis, settlement H+2.

1Daftarkan URL endpoint di aplikasi Anda

Klik Tambah Webhook di atas, isi URL server Anda (harus HTTPS di production) dan pilih event yang ingin diterima. Simpan secret key yang muncul — hanya ditampilkan sekali.
2Terima dan verifikasi request dari Saya Bayar

Setiap kali event terjadi, server Saya Bayar akan mengirim HTTP POST ke URL Anda dengan header berikut:
Content-Type: application/json
X-Webhook-Signature: sha256_hash_dari_payload
X-Webhook-Event: invoice.paid

Contoh payload JSON yang diterima:

{
  "event": "invoice.paid",
  "data": {
    "invoice_id": "d3b6c53e-22c5-4a43-...",
    "invoice_number": "INV-2024-001",
    "amount": 150000,
    "amount_unique": 150123,
    "status": "paid",
    "payment_channel": "BCA",
    "paid_at": "2024-03-27T03:00:00.000Z"
  },
  "timestamp": "2024-03-27T03:00:05.000Z"
}

3Verifikasi signature & proses event

Selalu verifikasi signature sebelum memproses data, agar request tidak bisa dipalsukan. Pilih bahasa yang Anda gunakan:


const express = require('express')
const crypto = require('crypto')
const app = express()

// PENTING: gunakan raw body, bukan JSON parsed
app.use('/webhook', express.raw({ type: 'application/json' }))

const WEBHOOK_SECRET = 'whsec_xxxx...' // secret dari dashboard

app.post('/webhook', (req, res) => {
  const signature = req.headers['x-webhook-signature']
  const payload   = req.body.toString()

  // Verifikasi signature — HMAC-SHA256 standar
  const expected = crypto
    .createHmac('sha256', WEBHOOK_SECRET)
    .update(payload)
    .digest('hex')

  if (!crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expected))) {
    return res.status(401).json({ error: 'Invalid signature' })
  }

  const { event, data } = JSON.parse(payload)

  if (event === 'invoice.paid') {
    console.log('Invoice lunas:', data.invoice_number, '— Rp', data.amount)
    // → aktifkan akun, proses pesanan, kirim email konfirmasi
  } else if (event === 'invoice.expired') {
    console.log('Invoice kadaluarsa:', data.invoice_number)
    // → batalkan pesanan, kirim notifikasi ke customer
  } else if (event === 'invoice.cancelled') {
    console.log('Invoice dibatalkan:', data.invoice_number)
    // → kembalikan stok, refund jika perlu
  }

  res.json({ received: true })
})

app.listen(3000)

4Referensi Events
invoice.paidInvoice berhasil dibayar oleh customer
invoice.expiredInvoice melewati batas waktu pembayaran
invoice.cancelledInvoice dibatalkan oleh merchant
